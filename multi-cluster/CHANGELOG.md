# Changelog

All notable changes to the Multicluster Hub plugin are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the plugin uses
[semantic versioning](https://semver.org/).

## [0.2.0] — unreleased

### Added

- Compliance matrix on the Policies tab: every root policy against every cluster it is placed
  on, with the compliance of each cell, links to the policy and the cluster, and a filter that
  keeps only non-compliant and pending policies and clusters.

## [0.1.0] — 2026-10-20

First public release.
